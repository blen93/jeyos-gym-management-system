# Jeyos Hardhit Fitness Center
## Gym Management & Attendance System

**Created & Developed by Blenda Saragena**

A full-stack gym management and attendance system developed for Jeyos Hardhit Fitness Center.

## Main Features

- Member registration and profile management
- Membership tracking and renewal
- Attendance logging
- QR/barcode identification
- Hardware scanner support
- Duplicate check-in protection
- Admin authentication
- Remote administration over local Wi-Fi/LAN
- SQLite database
- Android APK deployment
- Offline/local-network operation
- Audio and visual scanner feedback

## Technology Stack

- HTML5 / CSS3 / JavaScript
- Java
- SQLite
- Android WebView
- Android Text-to-Speech
- Gradle
- Acode and Termux

## Architecture

Android Phone → WebView → Java LocalServer → SQLite → Local Wi-Fi → Remote Admin Device
